# FreshFind — Multi-page website

Pages included:
- `index.html` — Home / landing page
- `market-directory.html` — filterable market directory
- `market-detail.html?id=ikot` — reusable market detail page
- `produce-guide.html` — searchable/filterable produce catalogue
- `about.html` — About Us
- `contact.html` — Contact + Google Maps + browser geolocation

Shared files:
- `shared.css` — identical navbar, typography, buttons, footer, chatbot shell
- `app.js` — clock, mobile navigation, demo login/favourite, chatbot
- `markets.json` — market data
- `produce.json` — produce data
- `chatbot.json` — scripted chatbot data

Run locally with VS Code Live Server for JSON loading and browser geolocation.
The photography uses static Unsplash image URLs; no API/backend is used.
